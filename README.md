# W14B — Higher or Lower Game

## Project Description

A Higher or Lower Game developed using Vue.js, Vue Router, Axios, and vue-cookies.

## How to Run the Project

1. Clone the GitHub repository.
2. Open the project folder.
3. Install dependencies:

   `npm install`

4. Start the development server:

   `npm run serve`

5. Open `http://localhost:8080/login` in your browser.

## Game Instructions

1. Log in using the demo credentials.
2. Start with 100 points.
3. Enter a wager.
4. Click **Play Game**.
5. A random number is generated.
6. If the number is 50 or higher, you win and receive twice your wager as a payout.
7. If the number is below 50, you lose your wager.
8. Your points, wins, and losses are saved using cookies.

## Bonus Features

**Bonus 1:** Point wagering system with persistent cookie storage.

**Bonus 2:** Dynamic page titles and metadata, including author, description, and keywords.
